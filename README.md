# Cantada — projeto

Estrutura:

```
projeto-cantada/
├── index.html     # estrutura da página
├── css/
│   └── style.css  # visual (tema neon, animações)
└── js/
    └── script.js  # lógica (dodge do botão, calendário, fluxo de telas)
```

Como abrir:
1. Extraia o zip.
2. Abra a pasta `projeto-cantada` no VS Code.
3. Use a extensão **Live Server** (botão direito em `index.html` → "Open with Live Server"), ou apenas abra o `index.html` direto no navegador.

Nada aqui depende de build (sem npm/webpack) — é HTML/CSS/JS puro.
